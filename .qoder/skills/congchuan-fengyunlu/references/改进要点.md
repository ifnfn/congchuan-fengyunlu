# 第四至六回改进要点

---

## 第四回：刑部狱左公受严审 / 方孔时星夜奔枞阳

### 现有问题

1. **方孔时带方安国同行的逻辑不通**：方孔时狂奔回枞阳（跑死四匹马），带着一个幼童不可能跑这么快。方安国应走安全路线（船或慢路），由老仆/乳母提前送到姚家。
2. **方孔时到达姚家后的状态不够极端**：狂奔伤体+京城打探时已受暗伤，到姚家时应是虚脱被抬入，而非正常走进。
3. **托孤场景的情感重量不足**：方孔时临终把方安国托付给姚之兰，关键句"这个孩子，跟我姓方还是跟你姓姚，不重要。活着就行。"——这句话需要更长的铺垫，不是到了就说，而是撑完最后一段交代后油尽灯枯。

### 改进方向

- 开篇写方孔时在京城打探的暗伤（被锦衣卫盯梢时受过推搡或杖伤），为他后续油尽灯枯埋因。
- 方安国到姚家的过程单独一笔带过（老仆走船路，比方孔时早到两日）。
- 方孔时到姚家是被抬入的，撑完左案情报、方家藏书安排、方安国托付三件事后倒下。
- 托孤不是安排好的交接，而是一个父亲燃尽最后一点力气后的恳求。

## 第五回：锦衣卫三路查枞阳 / 方家失书紫阳楼空

### 现有问题

1. **锦衣卫查抄的节奏过快**：三路查（方家藏书楼、紫阳祠、六族关系）应有层次，不能一笔带过。
2. **紫阳祠弃子布置的过程未展开**：读者需要看到朱成璧是怎么提前布置弃子的，否则第六回取出真帛书时没有紧张感。
3. **方家藏书楼被焚的处理**：不能写成"一把火烧了"，要有具体场景——哪些书烧了（门面书）、哪些书没烧（已被朱成璧提前转移）、烧的时候谁在场、谁在远处看。
4. **方孔炤被带走的过程缺少细节**：他是主动投案还是被拖走？走之前做了什么？（应已在焚楼前把核心书册交给朱成璧）

### 改进方向

- 三路查按"方家→紫阳祠→六族关系"顺序展开，每路一个场景。
- 方家查抄：锦衣卫到藏书楼时楼已在烧（方孔炤提前安排的），只搜到残书和灰烬。
- 紫阳祠查抄：锦衣卫搜到画像背后的旧帛书弃子、旧印族谱残卷，觉得"不过如此"，未再深追。枯井三只书箱上层是旧簿香灰空架——看起来像已转移。
- 方孔炤被带走时应有最后一句话或最后一个动作——不煽情，只留一个读者可以记住的画面。

## 第六回：朱明熙井底守一纸 / 三家灯下议存亡

### 现有问题

1. **朱明熙取出真帛书的过程太轻松**：一个幼主从枯井书箱下取出帛书，应有紧张感——他是否被发现？是否有人帮他？哑仆是否在场？
2. **帛书取出后的传递链不够清晰**：帛书从朱明熙→姚家后院→方若兰→姚之兰→左光先→方孔时，这条链需要每一步都有具体场景。
3. **三家会商的权力交接需要更清晰的层次**：方若兰坐主位是姚之兰让给她的，方孔时在座但不争——这是方家从父辈到女儿辈的权力转移，需要通过动作和沉默来体现，不能靠解释。
4. **方孔时之死的具体处理**：如果方孔时在第六回末或第七回死于姚家，第六回应是他最后的交代场景。油尽灯枯的过程需要写得克制——不嘶喊、不遗言连篇，只是灯下说着说着声音越来越轻，最后没有声音了。

### 改进方向

- 朱明熙取帛书：哑仆陪同，夜间行动。枯井很深，书箱很重，朱明熙年纪小手够不到底，哑仆用绳子把书箱吊上来，朱明熙在最底层的旧簿之下摸到帛书。
- 帛书传递链：每一步写一个短场景（不超过200字），重点是帛书经过每双手时那个人的反应——方若兰接过时手抖了一下、姚之兰接过时看了一眼没说话、左光先接过时沉默良久。
- 方孔时之死：灯下，他还在说藏书的事，声音越来越轻。姚之兰凑近听，他已经说完了。灯还亮着，人已经没了。方安在门外，没有进去。

---

## 通用改进原则

1. **每一回的高潮场景不超过一个**：第四回是托孤、第五回是焚楼/查抄、第六回是取帛书/三家会商。其他场景为高潮服务，不抢戏。
2. **物件的状态必须前后统一**：如果帛书在第六回是"折痕很深"的，那后面提到时不能变成"平整如新"。
3. **方安在这些场景中是旁观者**：他不是主角，他是记录者。他的记录方式（记什么、不记什么、怎么记）本身就是戏。
