# 章节修改检查清单

每章修改前，按以下十类逐项检查，标注"通过/需改/不适用"。

---

## 1. 时间线

- [ ] 本章事件是否与前文时间线一致？（天启四年秋为起点，逐回推进）
- [ ] 季节、月令、天气是否与时间匹配？
- [ ] 是否存在时间跳跃？如有，方安记录是否标注了间隔？
- [ ] 同一夜内的事件顺序是否合理？

## 2. 人物在场

- [ ] 本章出场的每个人物，此时此地是否应该在？（方孔炤第七回死后不再出现；左光斗第一回后不再出现等）
- [ ] 不在场的人物是否被错误提及或暗示在场？
- [ ] 方安作为记录者是否在场或能获知本章事件？

## 3. 物象一致性

- [ ] 本章涉及的物象（石狮、铜铃、铁胆、帛书、折扇、钥匙等）状态是否与前文一致？
- [ ] 石狮三阶态是否锁定在正确阶段？
- [ ] 铜铃物象链是否按顺序推进（藏声→挂声→断铃沉水）？
- [ ] 帛书流转路径是否与SKILL.md中的路径一致？
- [ ] 同类物件在不同场景中物理状态是否统一？

## 4. 对话质量

- [ ] 每段对话是否有具体筹码驱动？（不谈道理，只谈条件）
- [ ] 对话中是否有解释性废话？（"我是因为……才……"——删）
- [ ] 对话结束时是否有一件事改变了？
- [ ] 张家对话是否符合"少说、不解释、只递一句"的家学？
- [ ] 对话是否已删到不能再删？

## 5. 方安记录

- [ ] 本章是否有方安记录收束？
- [ ] 记录是否包含三层功能：记事件、记判断、记时间？
- [ ] 记录句是否短、准、有分量？
- [ ] 方安记法是否符合当前阶段的演化（第八回同页两名→第九回选择性不记→第十回字词更改）？

## 6. 空间与地理

- [ ] 六族议事场所是否在正确地点？（第一板块：啖椒堂/紫阳祠/藏书楼三处并列；第二板块起：浮山洞单点）
- [ ] 浮山秘洞的知情范围是否正确？（第一板块：只朱家；第二板块：仍只朱家；第三板块：六族）
- [ ] 方若兰与吴世英浮山半隐居的地理是否在"旧路口外围、草寮、不入秘洞"范围内？
- [ ] 方家藏书楼日常在方家庄园，不是浮山。是否违反？

## 7. 情感线

- [ ] 方吴情感是否符合当前阶段？（第一板块只积不发；第二板块断铃→决裂；第三板块生死并置）
- [ ] 第一板块内是否写了方若兰"心动"或吴世英"想她"？（违规——所有情感靠物象与步伐）
- [ ] 第一板块内两人是否有直接对话、肢体接触、互相递物？（违规）

## 8. 家族口径

- [ ] 朱家行为是否符合"救族之家"定位？
- [ ] 姚家行为是否符合"保族之家"定位？
- [ ] 张家行为是否符合"只递一个字、从不出面"的家学？
- [ ] 吴家行为是否符合当前阶段（第一阶段抢田/第二阶段谋书/第三阶段决裂）？
- [ ] 方孔炤是否在第七回后彻底退场？（无出家、无改名、无"弘智"）

## 9. 微观修订规则

- [ ] 物象细节是否制造了无用疑问？（短笺、纸条的状态细节只服务情节功能）
- [ ] 是否有"火燎黑""雨水泡皱"等随意损伤描写？（除非后文要追问来历，否则删）
- [ ] 同类物象改动后是否全回同步？
- [ ] 结尾是否依赖固定套句？（"墨迹未干""水声还在流"——检查是否有更好选择）
- [ ] 是否有看似有触感但无功能的物理细节？（删）

## 10. 结尾收束

- [ ] 本章结尾方式是什么？（方安记录 / 物象 / 远景空间）
- [ ] 是否与前一章结尾方式重复？
- [ ] 结尾是否打开了后文暗线？
- [ ] 远景留白是否自然，不依赖套句？
